# Reply-клавіатури

Reply-клавіатури показують користувачеві готові варіанти тексту. На відміну від inline-кнопок, натискання відправляє звичайне повідомлення.

## Створення клавіатури

```js
bot.command('city', 'Обрати місто', (ctx) =>
  ctx.reply('Яке місто?', {
    keyboard: [
      ['Київ', 'Львів'],
      ['Одеса'],
      ['Скасувати'],
    ],
  }),
);
```

`keyboard` — це масив рядків, де кожен рядок — масив текстів кнопок.

## Обробка вибору

Кнопка відправляє текст як звичайне повідомлення. Обробляється через `bot.on('message')`:

```js
const CITIES = ['Київ', 'Львів', 'Одеса'];

bot.on('message', (ctx) => {
  const text = ctx.message.Text ?? '';

  if (text === 'Скасувати') {
    return ctx.reply('Скасовано.', { removeKeyboard: true });
  }

  if (CITIES.includes(text)) {
    return ctx.reply(`Ви обрали: ${text}`, { removeKeyboard: true });
  }
});
```

## Прибрати клавіатуру

```js
ctx.reply('Готово!', { removeKeyboard: true });
```

Клавіатура зникне після надсилання повідомлення.

## Пріоритет розмітки

За один виклик можна передати лише одну розмітку. Працює пріоритет:

1. `removeKeyboard: true`
2. `keyboard`
3. `buttons`

| Передано | Результат |
| --- | --- |
| `{ removeKeyboard: true, keyboard: [...] }` | Клавіатуру знято |
| `{ keyboard: [...], buttons: [...] }` | Показується `keyboard` |
| `{ buttons: [...] }` | Показуються inline-кнопки |

<Callout type="warn" title="Обмеження">
  - Reply-клавіатура завжди одноразова (`Once: true`)
  - Неможливо одночасно показати reply- та inline-клавіатуру
</Callout>

## Підказка в полі введення

Передайте `placeholder`, щоб замінити стандартну підказку в полі введення, поки клавіатура активна:

```js
ctx.reply('Оберіть місто:', {
  keyboard: [['Київ', 'Львів'], ['Одеса']],
  placeholder: 'Оберіть місто або натисніть кнопку',
});
```

## Приклад: Меню навігації

```js
const showMenu = (ctx) => {
  return ctx.reply('Головне меню:', {
    keyboard: [
      ['📊 Статистика', '⚙️ Налаштування'],
      ['❓ Допомога'],
    ],
  });
};

bot.command('menu', 'Меню', showMenu);

bot.on('message', async (ctx) => {
  const text = ctx.message.Text ?? '';

  switch (text) {
    case '📊 Статистика':
      await ctx.reply('Ваша статистика: ...');
      return showMenu(ctx);

    case '⚙️ Налаштування':
      await ctx.reply('Налаштування:', {
        keyboard: [['🔔 Сповіщення', '🔒 Приватність'], ['◀ Назад']],
      });
      return;

    case '❓ Допомога':
      await ctx.reply(ctx.help());
      return showMenu(ctx);

    case '◀ Назад':
      return showMenu(ctx);
  }
});
```

## Приклад: Опитування

```js
bot.command('poll', 'Опитування', (ctx) =>
  ctx.reply('Яка ваша улюблена мова програмування?', {
    keyboard: [
      ['JavaScript', 'TypeScript'],
      ['Python', 'Go'],
      ['Rust', 'C++'],
      ['Інша'],
    ],
  }),
);

bot.on('message', (ctx) => {
  const text = ctx.message.Text ?? '';
  const languages = ['JavaScript', 'TypeScript', 'Python', 'Go', 'Rust', 'C++', 'Інша'];

  if (languages.includes(text)) {
    // Зберегти вибір у базу даних
    return ctx.reply(`Дякуємо! Ви обрали: ${text}`, { removeKeyboard: true });
  }
});
```

## Команди для приватних чатів

Reply-клавіатури зручні в особистих діалогах. Поєднуйте з `scope: 'private'`:

```js
bot.command({
  name: 'city',
  description: 'Обрати місто',
  scope: 'private',
  run: (ctx) => ctx.reply('Яке місто?', {
    keyboard: [['Київ', 'Львів', 'Одеса']],
  }),
});
```

Пам'ятайте, що `scope` лише передається Yurba і локально не перевіряється.

## Відмінності від inline-кнопок

| Характеристика | Reply-клавіатура | Inline-кнопки |
| --- | --- | --- |
| Розташування | Нижче поля введення | Під повідомленням |
| Дія | Відправляє текст | Відправляє callback / відкриває URL |
| Збереження | Одноразова (`Once: true`) | Постійна, поки не змінити |
| Обробка | `bot.on('message')` | `bot.callback()` |
| Вигляд | Текстові кнопки | Кольорові кнопки зі стилями |
