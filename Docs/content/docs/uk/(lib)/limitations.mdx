# Обмеження

Цей список описує функціональність, яка **відсутня** в поточній версії Yurst.

<Callout type="warn" title="Межі реалізації">
  Це не помилки, а свідомі обмеження. Якщо вам потрібна така поведінка, реалізуйте її у своєму коді.
</Callout>

## Відсутні можливості

### Команди

| Обмеження | Рішення |
| --- | --- |
| `scope` не перевіряється локально | Перевіряйте тип чату в обробнику |
| Немає вбудованого cooldown | Реалізуйте cooldown самостійно |
| Немає middleware для команд | Обробляйте загальну логіку на початку handler |

### Повідомлення

| Обмеження | Рішення |
| --- | --- |
| `ctx.reply()` не розбиває довгі тексти | Діліть повідомлення самостійно |
| Немає методу для видалення повідомлень | Використовуйте `api('DELETE', ...)` |

### Клавіатури

| Обмеження | Рішення |
| --- | --- |
| За один раз — лише одна розмітка | Надішліть два повідомлення |
| Reply-клавіатура завжди `Once: true` | Неможливо змінити |

### Callback-кнопки

| Обмеження | Рішення |
| --- | --- |
| Маршрутизація: лише точний збіг і префікс до `:` | Парсіть `ctx.data` самостійно |
| Немає валідації дій кнопки | Вказуйте одну дію (`data`/`url`/`copy`/`command`) |

### Inline

| Обмеження | Рішення |
| --- | --- |
| Немає форматування результатів (markdown) | — |
| Немає фото/файлів у результатах | — |

### Архітектура

| Обмеження | Рішення |
| --- | --- |
| `bot.start()` не захищений від повторного виклику | Викликайте один раз |
| Немає dependency injection | — |
| Немає плагінів | — |

## Нюанси поведінки

### Невідомі команди

```js
bot.command('ping', 'Ping', (ctx) => ...);

bot.on('message', (ctx) => {
  // Сюди НЕ потрапить /ping
  // Сюди НЕ потрапить /unknown
});
```

Невідома команда:
- Ігнорується
- Не потрапляє до `bot.on('message')`
- Логується в debug-режимі

### Помилки в обробниках

```js
bot.on('message', async (ctx) => {
  throw new Error('Помилка!');
  // Наступний handler не викликається
});

bot.on('message', async (ctx) => {
  // Цей код не виконається
});
```

При помилці:
- Обробка цього оновлення зупиняється
- Наступні listeners не викликаються
- Помилка логується
- Процес продовжує працювати

### Паралельність

```js
let counter = 0;

bot.on('message', async (ctx) => {
  const c = counter++;
  await new Promise(r => setTimeout(r, 1000));
  // counter вже змінився іншим обробником!
});
```

Різні оновлення обробляються **одночасно**. Якщо потрібна синхронізація:
- Використовуйте черги
- Використовуйте м'ютекси
- Зберігайте стан у БД з транзакціями

### WebSocket

| Ситуація | Поведінка |
| --- | --- |
| Node.js < 22 без пакету `ws` | Автоматичний перехід на polling |
| Помилка автентифікації (код 3000) | Процес завершується |
| `WS_MAX_FAILS` невдалих спроб | Автоматичний перехід на polling |

### Помилка 401

При невалідному токені:
- `GET /bot/me` → 401 → процес завершується
- WebSocket → код 3000 → процес завершується

## Внутрішні модулі

Публічним API є лише експорти з `index.js`. Решта файлів під `src/` є внутрішньою реалізацією і може змінюватися без попередження.

## Тести

Пакет містить юніт-тести для `ButtonsBuilder`, нормалізації назв команд і формування розмітки:

```sh
npm test
```

Інтеграційних тестів, які звертаються до справжнього API Yurba, немає — для перевірки транспорту та доставки запускайте бота в dev-режимі.

## Поради

### Обробка помилок

```js
bot.on('message', async (ctx) => {
  try {
    // Ваш код
  } catch (err) {
    L.error('handler', err);
    await ctx.reply('Сталася помилка. Спробуйте пізніше.');
  }
});
```

### Перевірка scope

Бібліотека не надає готового прапорця «приватний чат». Якщо потрібна локальна перевірка, візьміть сирий об'єкт діалогу з `ctx.message.Dialog` і подивіться його поле `Type` у реальному оновленні (наприклад, увімкнувши `YURST=dev`). Набір значень визначає Yurba, тому не покладайтеся на вгаданий формат ID діалогу.

### Cooldown

```js
const cooldowns = new Map();

bot.on('message', (ctx) => {
  const userId = ctx.user?.ID;
  const now = Date.now();
  const last = cooldowns.get(userId) ?? 0;

  if (now - last < 1000) {  // 1 секунда
    return;  // Ігноруємо
  }

  cooldowns.set(userId, now);
  // Обробка
});
```
