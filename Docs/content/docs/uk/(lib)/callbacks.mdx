# Callback-кнопки

Inline-кнопки відображаються під повідомленням та дозволяють користувачу взаємодіяти з ботом без введення тексту.

## Створення кнопок

Кнопки передаються в опції `buttons` методів `reply()` та `send()`:

```js
ctx.reply('Меню', {
  buttons: [
    [
      { text: 'Відкрити', data: 'menu:open', style: 'primary' },
      { text: 'Документація', url: 'https://yurba.one' },
    ],
    [{ text: 'Копіювати', copy: 'текст для копіювання' }],
    [{ text: 'Команда', command: '/help' }],
  ],
});
```

### Структура

`buttons` — це масив рядків, де кожен рядок — масив кнопок.

```js
buttons: [
  [button1, button2],  // перший рядок
  [button3],           // другий рядок
]
```

## Типи кнопок

| Дія | Поле | Опис |
| --- | --- | --- |
| Callback | `data` | Надсилає callback боту |
| Посилання | `url` | Відкриває URL у браузері |
| Копіювання | `copy` | Копіює значення в буфер обміну |
| Команда | `command` | Виконує slash-команду |

### Callback-кнопка

Найпоширеніший тип. При натисканні бот отримує callback-подію:

```js
ctx.reply('Оберіть дію:', {
  buttons: [
    [
      { text: 'Підтвердити', data: 'confirm', style: 'success' },
      { text: 'Скасувати', data: 'cancel', style: 'danger' },
    ],
  ],
});
```

### Кнопка-посилання

Відкриває URL при натисканні:

```js
ctx.reply('Корисні посилання:', {
  buttons: [
    [{ text: 'Yurba', url: 'https://yurba.one' }],
    [{ text: 'Документація', url: 'https://docs.yurba.one' }],
  ],
});
```

### Кнопка копіювання

Копіює значення в буфер обміну:

```js
ctx.reply('Скопіюйте промокод:', {
  buttons: [
    [{ text: 'Скопіювати', copy: 'PROMO2024' }],
  ],
});
```

### Кнопка команди

Виконує slash-команду:

```js
ctx.reply('Швидкі дії:', {
  buttons: [
    [{ text: 'Допомога', command: '/help' }],
    [{ text: 'Налаштування', command: '/settings' }],
  ],
});
```

## Стилі кнопок

Необов'язкове поле `style` змінює вигляд кнопки:

| Стиль | Вигляд |
| --- | --- |
| `'primary'` | Основна дія (виділено) |
| `'success'` | Підтвердження (зелений) |
| `'danger'` | Небезпечна дія (червоний) |

```js
ctx.reply('Видалити елемент?', {
  buttons: [
    [
      { text: 'Так', data: 'delete:yes', style: 'danger' },
      { text: 'Ні', data: 'delete:no', style: 'primary' },
    ],
  ],
});
```

<Callout type="warn" title="Одна дія на кнопку">
  Yurst не перевіряє взаємну виключність полів. Вказуйте рівно одну дію (`data`, `url`, `copy` або `command`) на кнопку.
</Callout>

## ButtonsBuilder

Для меню з багатьма кнопками зручно використовувати builder з публічного експорту пакета:

```js
import { ButtonsBuilder } from 'yurst';

const buttons = new ButtonsBuilder()
  .row()
  .link('Документація', 'https://yurba.one')
  .command('Допомога', '/help')
  .row()
  .callback('Підтвердити', 'action:confirm').success()
  .callback('Скасувати', 'action:cancel').danger()
  .build();

await ctx.reply('Оберіть дію:', { buttons });
```

`row()` починає новий рядок. Додавайте кнопки методами `link(text, url)`, `command(text, command)`, `callback(text, data)` або `copy(text, value)`. `btn()` і `cmd()` — короткі псевдоніми для `callback()` і `command()`.

Методи стилю застосовуються до **останньої доданої кнопки**:

| Метод | Ефект |
| --- | --- |
| `.primary()` | Основна дія |
| `.success()` | Успішна дія |
| `.danger()` | Небезпечна дія |
| `.gray()` | Скидає явний стиль до стандартного вигляду |

`build()` повертає масив рядків для `ctx.reply()` та `ctx.send()`. `buildMarkup()` повертає Yurba-формат `{ Inline: [...] }`.

### Побудова з даних

У циклі викликайте `row()` перед кнопкою, яка має починати новий рядок:

```js
const items = Array.from({ length: 12 }, (_, index) => ({
  id: String(index + 1),
  name: `Елемент ${index + 1}`,
}));

const menu = new ButtonsBuilder();
items.forEach((item, index) => {
  if (index % 3 === 0) menu.row();
  menu.callback(item.name, `item:${item.id}`).gray();
});

await ctx.reply(`Знайдено: ${items.length}`, { buttons: menu.build() });
```

## Обробка натискань

### Реєстрація обробника

```js
bot.callback('menu:open', async (ctx) => {
  await ctx.answer();
  await ctx.replace('Меню відкрито!');
});
```

### Правила маршрутизації

`bot.callback(pattern, handler)` спрацьовує коли `ctx.data`:

1. Дорівнює `pattern` точно
2. Починається з `pattern + ':'`

| Шаблон | `ctx.data` | Збіг |
| --- | --- | --- |
| `'menu'` | `'menu'` | ✅ |
| `'menu'` | `'menu:open'` | ✅ |
| `'menu'` | `'menux'` | ❌ |
| `'menu:open'` | `'menu:open'` | ✅ |
| `'menu:open'` | `'menu:open:extra'` | ✅ |

Перемагає **перший зареєстрований** збіг.

### Необроблені callback-и

Якщо жоден обробник не підійшов, Yurst автоматично викликає `ctx.answer()` щоб зняти індикатор завантаження з кнопки.

## Відповідь на натискання

### ctx.answer()

**Обов'язково викликайте першим**, до важких операцій!

```js
await ctx.answer();                              // зняти індикатор
await ctx.answer('Збережено!');                  // toast-повідомлення
await ctx.answer({ text: 'Увага!', alert: true }); // модальне вікно
await ctx.answer({ url: 'https://yurba.one' });   // відкрити URL
```

<Callout type="warn" title="Таймаут 8 секунд">
  Сервер очікує відповідь ~8 секунд. Завжди викликайте `answer()` перед довгими операціями. Повторні виклики безпечні — вони ігноруються.
</Callout>

## Оновлення повідомлення

### ctx.replace(text, options)

Замінює текст повідомлення з кнопкою:

```js
bot.callback('counter:inc', async (ctx) => {
  await ctx.answer();
  await ctx.replace('Лічильник: 5', {
    buttons: [[{ text: '+', data: 'counter:inc' }]],
  });
});
```

Викидає помилку якщо `ctx.message` відсутній.

### ctx.editMarkup(options)

Змінює лише кнопки:

```js
await ctx.editMarkup({
  buttons: [[{ text: 'Оновлено', data: 'updated' }]],
});

// Прибрати кнопки
await ctx.editMarkup({ removeKeyboard: true });
```

## Приклад: Лічильник

```js
const counters = new Map();

const view = (n) => [
  [
    { text: '−', data: 'cnt:dec', style: 'danger' },
    { text: String(n), data: 'cnt:noop' },
    { text: '+', data: 'cnt:inc', style: 'success' },
  ],
  [{ text: 'Скинути', data: 'cnt:reset', style: 'primary' }],
];

bot.command('counter', 'Лічильник', (ctx) =>
  ctx.reply('Лічильник: 0', { buttons: view(0) }),
);

bot.callback('cnt', async (ctx) => {
  await ctx.answer();

  const id = ctx.message?.ID;
  const action = ctx.data.split(':')[1];
  let n = counters.get(id) ?? 0;

  switch (action) {
    case 'inc': n++; break;
    case 'dec': n--; break;
    case 'reset': n = 0; break;
  }

  if (id) counters.set(id, n);
  await ctx.replace(`Лічильник: ${n}`, { buttons: view(n) });
});
```

<Callout>
  Стан зберігається в пам'яті процесу. Після перезапуску бота дані зникнуть. Для постійного зберігання використовуйте базу даних.
</Callout>

## Приклад: Пагінація

```js
const items = ['Яблуко', 'Банан', 'Апельсин', 'Груша', 'Кавун'];

const view = (page, total) => {
  const btns = [
    [
      { text: '◀', data: `page:${page - 1}` },
      { text: `${page + 1}/${total}`, data: 'page:noop' },
      { text: '▶', data: `page:${page + 1}` },
    ],
  ];
  return btns;
};

bot.command('list', 'Список фруктів', (ctx) => {
  const totalPages = Math.ceil(items.length / 1);
  const item = items[0];
  return ctx.reply(item, { buttons: view(0, totalPages) });
});

bot.callback('page', async (ctx) => {
  await ctx.answer();

  const page = parseInt(ctx.data.split(':')[1]);
  const totalPages = Math.ceil(items.length / 1);

  if (page < 0 || page >= totalPages) return;

  const item = items[page];
  await ctx.replace(item, { buttons: view(page, totalPages) });
});
```
